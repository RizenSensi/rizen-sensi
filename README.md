# Rizen Sensi

Site oficial da Rizen Sensi, desenvolvido como página estática para publicação no GitHub Pages.

## Publicar no GitHub Pages

1. No repositório do GitHub, abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde o GitHub gerar o endereço público.

Todos os botões de atendimento apontam para o servidor oficial: https://discord.gg/pN9USTH9sj
